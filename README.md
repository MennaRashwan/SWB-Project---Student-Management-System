# SWB-Project---Student-Management-System
A lightweight command-line application built in C++ to manage student academic records. It supports adding, searching, updating, and deleting student data, calculating grade averages, ranking top performers, and persistent data storage using file handling.

*Extended Description*
Project OverviewThe Student Record Management System is a robust terminal-based application designed to streamline the administration of student academic data. Built using C++ and the Standard Template Library (STL), this project demonstrates efficient data management through structured programming and persistent storage techniques.The system allows users to track student profiles including unique IDs, full names, and grades across five core subjects: Logic, Statistics, Numerical Analysis, Machine Learning, and Control Systems.Key FeaturesComplete CRUD Operations: Add new student profiles, view all records, update existing information, and remove records via a unique ID.Persistent Storage: Integrated file handling (fstream) ensures that student data is saved to a students.txt file and automatically reloaded upon starting the application.Dynamic Search: Search for specific student records using either their Unique ID or Full Name.Academic Performance Analysis: * Automatic calculation of average grades for every student.Top Performer Ranking: A dedicated feature that sorts and displays students based on their total academic rating using custom sorting algorithms.Data Validation: Includes input validation to ensure grades remain within the $0$ to $100$ range and prevents duplicate ID entries.Technical ImplementationLanguage: C++Data Structures: Utilizes std::vector for dynamic memory management and struct for organized data modeling.Algorithms: Implements std::sort with lambda expressions for custom ranking logic and linear search for data retrieval.File I/O: Uses ifstream and ofstream for seamless data persistence between sessions.
